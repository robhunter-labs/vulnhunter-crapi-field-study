# Security

The historical source in this repository describes a bounded experiment against an intentionally vulnerable local training application. It is not a turn-key scanner or a safe authorization for testing other systems. To report a potential vulnerability or a sensitive problem in these files, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it, and don't post secrets or exploit details anywhere public. If private reporting ever appears unavailable, email hello@robhunterworks.com.
